# YouTube Thumbnail & Packaging Director

## Overview
Turn dark cinema into high-CTR YouTube clicks without cheap collage clickbait or invisible black-mud frames. One package must pass the **150px Mobile Readability Test** in 0.2 seconds and funnel Shorts viewers directly into long-form watch sessions.

## Iron Laws — No Exceptions
1. **ZERO Vague 2-Word Titles or Technical/Legal Jargon:** Every long-form title MUST use timeless primal English (`King, Queen, Mother, Child, Soldier, Prisoner, Bride, Dragon, Beast, Monster, Forest, Pit, Blood, Crown`) executing `Recognizable Human + Extraordinary Creature/Encounter + Impossible/Heartbreaking Twist` (`<= 95` chars hard cap, **front-load core hook `<= 60` chars**). Ban dry bureaucratic/sci-fi nouns (`Notary, Quarantine, Garrison, Sea-Lock, Disinheritance, Aquifer`). Zero ending-twist spoilers.
2. **Dedicated `16:9` Thumbnail Generation:** NEVER crop a dark/motion-blurred `2.39:1` video still or leave hollow empty sky bars for overlaid clickbait text. Render a purpose-built `16:9` still (`flow_prompt_plate` / `keyframe_build`) directly depicting the core contradiction event inside the film.
3. **50%+ Figure-Ground Luminance Delta (The `150px` Squint Rule):** Separate dark armor/creature silhouettes sharply against bright overcast limestone mist, sunlit sandstone haze, or (for subterranean scenes) a bright `5600K` stone skylight shaft + pale mist rim. **Max `2` dominant figures** (any optional 3rd subordinate figure restricted to `< 8%` recessed silhouette, never 3 equal subjects) + `1` saturated focal prop/eye highlight. Zero YouTube arrows, circles, or text collage.
4. **Bottom-Right Safe Zone:** Never place hands, faces, or critical objects in the lower-right `22%` quadrant masked by YouTube duration badges.
5. **1 Film → 3–4 Feeder `9:16` Shorts + `MULTISUB`:** Use `clip_plan_viral` and `clip_render_viral` (`active-speaker` / center-safe framing) on top confrontation scenes + localize ASS/SRT captions for global non-English watch time.

## Red Flags — Reject Package If Caught
| Package Failure | Exact Cure |
| --- | --- |
| Black/orange cave fight frame cropped to 16:9 | Separate `16:9` overcast courtyard confrontation still with pale stone rim |
| Static dead space *"left third empty for title placement"* | Fill frame purposefully with the **1 physical contradiction** (creature snapping shackle onto king's gold cuff) |
| Cryptic fantasy noun title (*"CONCORDAT"*, *"ASH CLAUSE"*) | Rewrite using `Human + Creature + Impossible Twist` formula |
| Long-form launched alone with zero Shorts | Generate 3 hook-first `24–38s` vertical clips via `clip_render_viral` pointing to the feature |
