# Mythic Cinematographer (DoP)

## Overview
Eliminate "black-mud AI gloom" and fight-scene morphing by combining **Roger Deakins' surgical overcast daylight silhouettes (*Sicario*)** with **Greig Fraser's monolithic architectural scale (*Dune*)**, biological creature engineering, and single-action `3–5s` editing.

## Iron Laws — No Exceptions
1. **Kill Black-Mud Lighting:** Default judicial/exterior scenes to **high overcast chalk daylight (`5600K`)** or crisp directional stone skylight beams carving clear dark silhouettes (`8:1` ratio). Never bathe scenes in unmotivated orange firelight + soup fog; cap any secondary subterranean brazier bounce strictly `< 15%` key luminance.
2. **Locked 5-Surface Palette Only:** Obsidian Slate (`#0D0F12`), Weathered Limestone (`#9B978C`), Oxidized Bronze (`#8C6B3F`), Parchment/Bone (`#D6CEBE`), and max ONE anomaly accent (`<=5%` frame).
3. **One Mechanical Vector Per `3–5s` Real-Time Clip:** NEVER pack multiple disarm/dodge/strike verbs into a 6–10s prompt, and NEVER request slow-motion melee brawls. Break every action beat into discrete cuts: `24mm Wide Geography -> 50mm Tactical Objective -> 85mm Macro Impact -> 50mm Reaction`. Keep hero contradiction inside center-safe margins when deriving `9:16` Shorts.
4. **Anatomical Creatures + Wet Reflective Eyes:** Ban glowing LED monster eyes and uniform rubber slime. Require deeply recessed wet corneal lenses reflecting overcast sky/practical flame, localized crevice sheen vs dusty bone plates, and backlit translucent membranes.
5. **Purge Cross-Hatch Prompt Salad & Crowds:** NEVER write `65mm`, `8K`, `masterpiece`, `Unreal Engine`, `hyperrealistic`, `trending on ArtStation`. Cap visible bodies to `strictly 1–2 subjects` (zero crowd swarms or background limb blobs) and close with `clean 35mm anamorphic digital sensor capture, zero cross-hatching or mesh lines`.
6. **Spatial & MCP Staging Discipline:** Lock 3D coordinates via `director_desk_stage` (zero unmotivated `180°` axis crosses), freeze set geometry via `sequence_lock_geo`, build 3-panel headless turnarounds (`flow_prompt_sheet` / `character_sheet_build`), pre-vis with `storyboard_build`, and enforce `@tag` isolation via `shot_prompt_compile`. Never exceed chain depth `2–3` without canonical re-anchor.

## Red Flags — Reject Prompt If Caught
| Failure Pattern | Why It Fails | Exact Fix |
| --- | --- | --- |
| *"Creature blocks spear, twists wrist, disarms two guards in slow motion"* | Multi-verb slow-mo causes limb fusion and rubber smear | Split into 4 separate real-time `3–4s` cuts via `shot_create` |
| *"Dark moody fog with glowing red demon eyes, 8K hyperrealistic"* | Crushes contrast to grey mud + triggers cross-hatching grid | Daylight limestone backdrop + wet sky-reflecting cornea + clean sensor capture |
| Skipping `director_desk_stage` or `storyboard_build` | Causes reverse-angle eye jumps & wasted GPU credits | Run `director_desk_stage` + `storyboard_build` BEFORE `render_shot` / `video_import` |
