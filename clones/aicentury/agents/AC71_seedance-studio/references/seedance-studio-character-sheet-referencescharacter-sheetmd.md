## Core goal

Help the user turn a reference image or rough character idea into a complete production-grade character
sheet prompt.

**Recommended starter question:**

```
🎭 Upload a character reference image or describe your character. Include style, age, outfit, personality, and world if you know them.
```

Keep this short. Do not ask too many questions. If the user gives only a small idea, expand it
automatically.

---

## Character sheet output should include

- Full-body turnaround
- Front view
- 3/4 front view
- Side view
- Back view
- 3/4 back view
- Expressive head studies
- Hero cinematic portrait
- Costume breakdown
- Accessories and props
- Material close-ups
- Height reference
- Production notes
- Personality cues
- Motion and body-language notes
- Strict identity consistency rule

---

## Character identity fields

Name · Alias or symbolic role · Age · Height · Build · Ethnicity or design language · World/setting ·
Style · Personality · Core conflict · Emotional baseline · Movement rhythm · Signature behavior · Key prop ·
Wardrobe · Color palette

---

## Face design guidance

Describe:

- Face shape
- Bone structure
- Skin tone and texture
- Eye shape, color, spacing, expression
- Hair style, texture, volume, motion
- Distinctive marks
- Asymmetry
- Imperfections
- Emotional readability

Do not make characters generic. Every character must feel like a real performer with a story.

---

## Performance direction

The character should not look like a static mannequin. The character should feel like an actor captured
mid-moment.

Use: micro-expressions · lip tension · eyebrow movement · eye focus · subtle body tension · transitional
emotion · natural posture · movement habits · idle behavior.

---

## Wardrobe rules

Wardrobe should reveal personality and world. Describe: fabric type · fit · wear · stitching · wrinkles ·
dirt or aging · practicality · symbolic meaning · accessories · footwear · prop logic.

## Material accuracy

Include: fabric stretch · leather grain · metal scratches · skin softness · hair detail · dirt, smudges,
marks · surface realism · stylized realism if requested.

---

## Layout rules

The sheet should feel like a premium film production board. Avoid boring symmetrical grids. Use a clean
but art-directed layout.

Good layout language:

- Curated art direction board
- Slightly asymmetrical composition
- Premium studio pitch-board layout
- Handwritten-style production notes
- Annotation callouts
- Wardrobe breakdown
- Hero portrait section
- Turnaround section
- Expression study section
- Prop and material study section

---

## Style flexibility

Support any style:

- Pixar-style stylized realism
- Anime production sheet
- Semi-realistic cinematic design
- Hyper-realistic film concept art
- Fashion editorial character sheet
- Clay animation character design
- Cartoon comedy character sheet
- Fantasy game character concept
- Horror creature character sheet
- Nostalgic cel animation character sheet

---

## Reference image rules

If a user uploads a reference image, use it as the key identity reference. Preserve:

- Face identity
- Body proportions
- Hairstyle
- Outfit
- Color palette
- Props
- Style
- Personality impression

Do not change the character unless the user asks.

## Strict consistency rule

Always include:

```
Maintain perfect continuity in face, proportions, hairstyle, outfit, accessories, color palette, and material details across every view. No reinterpretation between angles.
```

---

## Character sheet prompt template

```text
Create a high-end cinematic character design sheet intended for a premium film or animation production.

Character:
[describe character]

Personality:
[traits, emotional baseline, inner conflict, behavior, movement rhythm]

Design Requirements:
- Full-body turnaround: front, 3/4 front, side, back, 3/4 back
- Consistent face, body proportions, hairstyle, outfit, colors, accessories, props, and materials across all views
- Expressive head studies from multiple angles
- Cinematic hero portrait
- Wardrobe, accessories, props, and material close-ups
- Height reference scale
- Handwritten-style production notes and callouts
- Dynamic art-directed layout, not a generic grid
- Slightly asymmetrical premium studio pitch-board composition

Performance Direction:
The character must feel like a real actor caught mid-moment, not a posed mannequin. Include natural posture, expressive eyes, subtle facial tension, and emotionally readable body language.

Style:
[requested style]
Cinematic lighting, emotional readability, high production value, sharp detail, clean background, professional concept art presentation.

Consistency Rule:
Maintain perfect continuity in face, proportions, hairstyle, outfit, accessories, color palette, and material details across every view. No reinterpretation between angles.

Negative:
No generic model sheet, no boring grid, no identity drift, no inconsistent outfit, no extra characters, no watermark, no logo, no blurry details, no plastic-looking materials unless requested.
```
