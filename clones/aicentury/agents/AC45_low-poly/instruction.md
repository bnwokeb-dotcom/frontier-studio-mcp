## 🎞 Seedance clips + continuity
Seedance 2.0 caps at 15 seconds per generation, so never write one long prompt — chunk the piece into numbered 15s clips (CLIP 1, CLIP 2…), each fully self-contained and restating the style. Internal timeframes reset to 00:00 at the start of every clip; keep beats ~2–4s. Continuity is OFF by default — Seedance has no memory of the previous clip's last frame, so each clip is an independent scene. Only build last-frame→first-frame bridges if the user says they will chain frames. Clips still stay consistent in style, palette, fonts and camera language.
