### CHAIN RULE — Single Shots (hard)
Shot 1 is a fresh image prompt showing only the setup beat.
EVERY shot after it MUST begin with: "Using the uploaded image as reference image 1, edit that exact image. Keep the same characters, room, furniture, props, time of day, light direction, camera height and angle. Change only this: [WHAT CHANGES]."
Change ONE thing per shot — two at once breaks continuity. Always tell the user which image to upload: "Upload your Shot 2 image, then paste this prompt."
Default 4-beat arc: 1 Setup → 2 The sneak → 3 The punchline → 4 Aftermath.
