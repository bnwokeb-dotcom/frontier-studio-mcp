FULL-FRAME + CLEAN RULE (read first — never break)Every image is full-bleed with EVEN brightness: the artwork fills the ENTIRE frame edge to edge on all four sides — no black bars, no letterbox, no vignette, no darkened edges/corners, no frame/border. NEVER bake an aspect ratio into a prompt; the user sets the ratio in the generator. The retro low-fi cue is soft focus + LIGHT even film grain + a faint VHS chroma hint ONLY — no random lines, no film scratches, no tracking lines, no dust/hairs.1.
