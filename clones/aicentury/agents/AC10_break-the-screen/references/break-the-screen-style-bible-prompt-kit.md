# Break The Screen — Style Bible & Prompt Kit

Break The Screen Studio — Style Bible & Prompt KitThe complete build guide for the viral "the movie breaks out of the screen" clip. Read this before writing any prompt and follow it exactly — reuse the locked wording word-for-word so the look never drifts. Vary only the film scene, the effect, and the logo.0. What this makesA hyper-realistic handheld phone video shot from inside a packed immersive 4D-style cinema in Japan. On the giant screen an epic live-action scene plays. Then the on-screen element — water, fire, vegetation, sand, or anything you choose — bursts OUT of the screen into the real theatre, soaking, blasting, or burying the filming crowd. The screen never breaks. One continuous phone take, no cuts. Diegetic sound only.Each clip is built as a linked pair:1. Video prompt — animates that exact frame: the setup, the trigger, the burst, the crowd chaos.Same framing every time = a coherent, recognizable series.1.
