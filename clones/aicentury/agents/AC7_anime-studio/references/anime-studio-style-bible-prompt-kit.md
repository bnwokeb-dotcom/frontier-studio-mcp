# Anime Studio — Style Bible & Prompt Kit

Anime Studio — Style Bible & Prompt KitThe complete build guide for Anime Studio's ONE locked look — a moody, cinematic modern adult seinen anime still. Read this before writing any prompt and follow it exactly: reuse the locked wording verbatim so the style never drifts. Vary only the subject, action, and shot.0. What Anime Studio makesCinematic "modern adult seinen anime film still" frames — the restrained, grown-up anime look: semi-realistic mature faces, soft brushed cel-shading, fine muted-brown linework (never heavy black ink), smooth matte surfaces, a muted desaturated grade, and low-key motivated lighting with deep soft shadows. It reads like a frame from a serious adult animated feature, not a bright TV cartoon.Each build is a linked pair: a still image prompt and a matching video prompt that continues it.1. The Locked Style — never dropThe Locked Style Clause — append this verbatim to the end of every image prompt:Modern adult seinen anime film still: semi-realistic mature adult faces with naturalistic proportions and restrained expressions, soft brushed cel-shading with gentle gradient modeling on skin, fine sparse muted-brown linework with soft edges, smooth matte surfaces, a muted desaturated cinematic colour grade, low-key atmospheric motivated lighting with deep soft shadows. No thick bold black outlines, no glossy highlights, no watercolour paper texture, no film grain, not photorealistic.Strongest keywords (rank order — always present):1. modern adult seinen anime film still — the anchor; forces the mature, cinematic register (not moe, not chibi, not kids' TV anime)2. semi-realistic mature adult faces ! naturalistic proportions ! restrained expressions3. soft brushed cel-shading with gentle gradient modeling (soft shading, not flat hard cel)
4. fine sparse muted-brown linework, soft edges — the line is thin, quiet, brown-toned5. smooth matte surfaces — no gloss, no plastic sheen6. muted, desaturated cinematic colour grade — subdued, filmic7. low-key atmospheric motivated lighting, deep soft shadows — the light comes from a real source in-scene8. cinematic composition — shot type + angle namedHard negatives (keep to ~3): no thick bold black outlines ! no glossy highlights ! not photorealistic.Forbidden words (they break the look — never use): thick black ink, bold outlines, chibi, moe, big sparkly eyes, cel banding, watercolour paper texture, gouache, film grain, glossy, oversaturated, vibrant, neon, photorealistic.The whole trick: SOFT. Soft brushed shading, soft thin brown lines, soft deep shadows, muted colour. If it looks hard-inked, glossy, saturated or cute, it has drifted.2.
