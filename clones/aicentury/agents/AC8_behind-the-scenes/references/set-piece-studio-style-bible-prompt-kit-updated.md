# Set Piece Studio — Style Bible & Prompt Kit (updated)

Set Piece Studio — Style Bible & Prompt Kit*Single source of truth. Every controller, template, disaster entry and worked example reuses this wording verbatim. One locked look only — the BIG-SPACE soundstage reveal. No day/night modes. The disaster + the city are the only main dials; camera vantage is a light optional sub-dial.*0. Premise (one line)A famous city or landmark is revealed to be a tiny practical MODEL inside an ENORMOUS, cavernous film-studio soundstage — a huge in-floor water tank, a blue chroma screen towering multiple storeys — as a massive practical disaster tears through the tiny model with real physical effects, shot as amateur behind-the-scenes phone footage. Full-size crew standing over the tiny model are the reveal.1. How Set Piece Studio worksOutput per run = ONE hero clip: exactly 1 text-to-image prompt + 1 matched text-to-video prompt. Never a multi-shot sequence unless the user explicitly asks.Two intake paths:¥Path A — Named place. The user names a city/landmark and picks a disaster. Translate the landmark into generic IP-safe wording (see ¤10) and drop it into the master image template.¥Path B — Uploaded photo. The user uploads a reference photo of a place/skyline. The image prompt must lead with: Set your uploaded image as reference image 1. Then rebuild that skyline as the tiny model in the huge tank. Still translate any named/branded landmarks to generic wording in the text.Engine-agnostic always: never name any AI tool, model or app anywhere inside a prompt body. Tools are named only in the affiliate footer.Never in a prompt: captions/subtitles/on-screen text; aspect ratios (no 16!9 / 9!16 / 1!1 / vertical / portrait / landscape / square); AI tool names; real brand logos/wordmarks; real people's likeness.
1b. ! THE BIG-SPACE LAW (the #1 rule — read this first)The single most common failure is the scene looking too small — a tabletop diorama in a modest room. The fix: the MODEL stays tiny, but the TANK, the SCREEN, the ROOM and the empty space around the model must all be ENORMOUS. It is a tiny miniature inside a cavernous industrial volume — never a desk model in a small room.The two scale reads, held together (this is the whole trick):1. Model-scale reveal: a full-size crew member is as TALL as the tallest model skyscraper — a standing adult dwarfs the miniature city. (Do NOT shrink the crew or enlarge the buildings.)2. Big-space cues, at the same time: that same crew member looks TINY against the towering screen (~1!7) and small in the room. The tank, the cyc wall and the FX plume are massive; the model is a tiny precise object inside a huge space.Framing law: the model occupies only the lower third of the frame; the top 50Ð60% is towering blue screen + high truss + empty air. Offset the model to one side with vast empty water/floor beside it. Let the tank run off the frame edges and the wall run off the top — nothing fully contained. Wide phone lens, deep depth of field.The set: a massive in-floor water tank sunk flush into the concrete floor (no table, no legs, no underside), roughly 20Ð35 m across, receding deep into the studio; thick grey hazard-striped concrete coping and coiled cables round the rim. The FX is the scale ruler — real water/ash/dust erupts many storeys high, cresting far up the towering screen with empty air still above it.2.
