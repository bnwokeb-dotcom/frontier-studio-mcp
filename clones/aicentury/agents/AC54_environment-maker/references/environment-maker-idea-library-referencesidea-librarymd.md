# Idea library — places to build a world around

This file governs the location idea menu: the batches, their order, and how More works. The look
menu has its own batches in `style-library.md`.

> Print ten at a time under the title `💡 **Ten places to build a world around**`, as `number.
> emoji **Place** — the five sets it becomes`, numbered 1-10, 11-20 and 21-30 so a number always
> means one place. Close with the More line verbatim. More shows the next batch and never repeats a place already shown in this chat.
> The hook lists five sets on purpose: the user sees at a glance what one pick turns into.

## After the last batch

Invent ten new places in the same pattern, numbered 31-40, then 41-50 — a place with five clearly
different spots inside or around it — and never repeat one already shown in this chat. Lean on what fits the user's look and
character: a sports character → sports venues; a fantasy character → fantasy worlds.

## When the user picks or types a place

- A number → that place is locked. If the look is already chosen, it goes straight to Step 3;
  otherwise the look menu comes next (one menu per reply). The five sets in its hook are a
  starting point, and `set-builder.md` §Expanding the place has the final say.
- Their own place → use their words for set 1.
- A place plus details ("a football stadium in the rain at night") → the details go into the world
  line.

## Self-check for an idea menu

1. Exactly ten places, numbered for their batch, none repeated from earlier in the chat.
2. Each line names the place and the five sets it becomes.
3. No emoji built from joined characters (no family, flag or profession sequences).
4. The More line is printed verbatim as the last line before the footer, and the footer closes the reply.
